Для роботи із програмою, вам потрібно зробити наступні налаштування:

  • TELEGRAM_PHONE_NUM - телефон вашого акаунту в Телеграм
  • TELEGRAM_API_ID - айді вашого застосунку в Телеграм
  • TELEGRAM_API_HASH - хеш вашого застосунку в Телеграм
  • TELEGRAM_POSTING_DELAY - пауза в секундах між постами
  • TELEGRAM_ITERATION_DELAY - пауза в секундах між циклами постінгу (для уникнення блокування)
  • TELEGRAM_API_DELAY - пауза в секундах між викликами API (для уникнення блокування)

Як отримати Telegram API ID та API Hash

  1. Перейдіть на сайт Telegram для розробників
    https://my.telegram.org
  2. Увійдіть за номером телефону
    • Введіть номер у міжнародному форматі (наприклад, +380...)
    • Отримайте код підтвердження у Telegram
    • Підтвердіть вхід
  3. Виберіть пункт API development tools
  4. Заповніть форму створення застосунку
    • App title — будь-яка назва (наприклад, My App)
    • Short name — коротка назва латиницею
    • Platform — Desktop або Other
    • URL — можна залишити порожнім
  5. Після збереження Ви отримаєте:
    • api_id — числовий ідентифікатор
    • api_hash — секретний ключ

Для активації штучного інтелекту для реплаїв, виконайте наступні дії:

1️⃣ Реєстрація в GroqCloud

  1. Перейдіть на сайт GroqCloud: https://console.groq.com
  2. Натисніть Sign Up або Log In
  3. Увійдіть за допомогою Google або email

Після входу Ви потрапите в Groq Console.

2️⃣ Отримання GROQ_API_KEY

  1. Відкрийте розділ API Keys
  2. Натисніть Create API Key
  3. Скопіюйте згенерований ключ, наприклад: 
    gsk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx

3️⃣ Збереження GROQ_API_KEY на сторінці ШІ Бот (або в налаштуваннях):

  1. Відкрийте ШІ Бот і збережіть ключ у полі GROQ_API_KEY
  2. За потреби налаштуйте personality, bio, mood, сценарії, цілі та природний стиль розмови

Параметри ШІ Бота:

  • GROQ_API_KEY - API-ключ Groq; якщо порожній, ШІ-відповіді вимкнені
  • GROQ_API_MODEL - модель Groq (за замовчуванням llama-3.3-70b-versatile)
  • GROQ_SYSTEM_MESSAGE - опційний базовий system prompt (додається перед personality/bio/mood)
  • AI_PERSONALITY - глобальна особистість бота (частина system prompt)
  • AI_BIO - глобальна біографія/бекграунд для контексту розмови (не Telegram profile bio)
  • AI_MOOD - глобальний поточний настрій бота
  • AI_SCENARIOS - JSON-каталог сценаріїв розмови для dropdown ([{id,name,description},…])
  • AI_GOALS - JSON-каталог цілей розмови для dropdown ([{id,name,description},…])
  • AI_CONVERSATION_STYLE - інструкції природної поведінки (паузи, жарти, короткі відхилення від сценарію)
  • AI_REPLY_STRATEGY - стратегія вибору повідомлення для реплаю: auto (пріоритет unanswered replies to us, інакше root), root, unanswered_to_us, any_thread (LLM обирає), last, random
  • AI_REPLY_DELAY_MIN_MS - мінімальна випадкова затримка (мс) перед ШІ-відповіддю
  • AI_REPLY_DELAY_MAX_MS - максимальна випадкова затримка (мс) перед ШІ-відповіддю; 0 вимикає затримку
  • AI_SKIP_PROBABILITY - додаткова ймовірність (0–100 %) пропустити хід навіть без skip від моделі
  • TELEGRAM_PM_MODE - режим приватних чатів: off (не відповідати), autoreply (статичний текст), ai (повний AI-чат з історією). Якщо параметр порожній, але задано TELEGRAM_PM_AUTOREPLY_TEXT, використовується autoreply
  • TELEGRAM_PM_AUTOREPLY_TEXT - статичний текст відповіді в PM для режиму autoreply
  • AI_PM_PROMPT - user-промпт для AI-режиму приватних чатів
  • AI_PM_SCENARIO - id сценарію з AI_SCENARIOS для PM (порожньо = без окремого сценарію)
  • AI_PM_GOAL - id цілі з AI_GOALS для PM (порожньо = без окремої цілі)
  • AI_PM_MOOD - override глобального AI_MOOD лише для приватних чатів
  • AI_PM_PERSONALITY - override глобального AI_PERSONALITY лише для приватних чатів
  • AI_PM_BIO - override глобального AI_BIO лише для приватних чатів

На головній сторінці для кожного пункту (групи/каналу) можна перевизначити ai_personality, ai_bio, ai_mood, обрати ai_scenario / ai_goal і reply_strategy. Режим «ведення дискусії» (target=@) передає в LLM дерево гілки з parent-child зв’язками. Для приватних чатів оберіть TELEGRAM_PM_MODE=ai на сторінці ШІ Бот.

Інші налаштування:

  • TELEGRAM_CH_POLL_INTERVAL - пауза між опитуванням каналів про нові пости
  • TELEGRAM_NEW_POST_DEBOUNCE - пауза перед публікацією коментаря під новим постом
  • TELEGRAM_NEW_POST_MAX_AGE - максимальний вік нового поста
  • TELEGRAM_PM_POLL_INTERVAL - пауза між перевіркою нових приватних повідомлень
  • TELEGRAM_PM_MODE / TELEGRAM_PM_AUTOREPLY_TEXT - див. секцію ШІ Бот вище
  • TELEGRAM_SEND_AS_CHANNEL - канал від імені якого надсилати повідомлення
  • TELEGRAM_RESTORE_BIO_DELAY - пауза перед відновленням інформації в профілі
  • TELEGRAM_EDIT_DELAY - пауза перед редагуванням повідомлення
  • TELEGRAM_DELETE_DELAY - пауза перед видаленням повідомлення
  • MULTI_ACCOUNT_MODE - активувати режим мультиакаунтів
  • ACCOUNT_CHANGE_FREQUENCY - частота перемикання акаунтів
  • TELEGRAM_THROTLING_RATE - відсоток пропускання
